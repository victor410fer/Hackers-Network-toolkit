# 🛡️ Hackers Network Toolkit

**Hackers Network Toolkit** is a lightweight, Python‑based ethical hacking & penetration testing toolkit.  
It runs on **Linux, Windows, macOS, and Termux (Android)** – no heavy dependencies, just Python 3.

---

## ⚙️ Tools Included

| Tool | Description |
|------|-------------|
| **Domain Extension Finder** | Checks domain availability across 20+ TLDs (`.com`, `.io`, `.tech`, etc.) |
| **Subdomain Finder** | Brute‑forces subdomains using a built‑in wordlist to discover live hosts |
| **URL Masking Tool** | Generates masked URLs (user‑info spoof / URL shortener) for educational use |

---

## 🚀 Getting Started

```bash
# Clone the repo
git clone https://github.com/victor410fer/Hackers-Network-toolkit.git
cd Hackers-Network-toolkit

# Run the toolkit
python3 toolkit.py
```

Choose an option from the menu and follow the prompts.
